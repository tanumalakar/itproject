First-time Firebase setup

  1. Create a Firebase project.
  2. Create a Firestore Database.
  3. Create a Storage bucket.
  4. Register a Web App and copy its Firebase config into the marked area in firebase-config.js.
  5. Open this Admin page and publish your projects.

After setup: you only use this page. You do not need to edit works.json or upload images to GitHub every time.
